# Inventory Management System

A simple, mobile-responsive inventory management app built with vanilla HTML, CSS, and JavaScript. Perfect for demos and prototypes.

## Features

- 📦 Add, edit, and delete inventory items
- 🔍 Real-time search across products, categories, and SKUs
- 📊 Dashboard with key statistics (total items, low stock alerts, total value)
- 🎨 Product images for each item
- 💰 Nigerian Naira (₦) currency formatting
- 📱 Fully mobile responsive design
- 🎨 Modern UI with deep green color theme
- ⚡ No server or database required - runs entirely client-side

## Technologies

- HTML5
- CSS3 (with Flexbox and Grid)
- Vanilla JavaScript (ES6+)
- Mock data (no backend required)

## Getting Started

Simply open `index.html` in your web browser. No installation or setup required!

```bash
# Clone the repository
git clone https://github.com/Webb222/small_inventory-app.git

# Navigate to the project
cd small_inventory-app

# Open index.html in your browser
```

## Mobile Responsive

The app is optimized for all screen sizes:
- Desktop (1024px+)
- Tablet (768px - 1023px)
- Mobile landscape (480px - 767px)
- Mobile portrait (360px - 479px)

## Demo Data

The app comes with 8 pre-loaded sample products including:
- Electronics (Laptops, Mice, Keyboards, Cables)
- Furniture (Chairs, Desks, Lamps)
- Office Supplies (Notebooks)

## Usage

1. **View Inventory**: Browse all items on the main dashboard
2. **Search**: Use the search bar to filter by name, category, or SKU
3. **Add Item**: Click the "+ Add Item" button and fill in the form
4. **Edit Item**: Click "Edit" on any product card to modify details
5. **Delete Item**: Click "Delete" to remove an item (with confirmation)
6. **Monitor Stock**: Check the dashboard for low stock alerts
